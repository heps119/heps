# heps119.com 계산기 법령근거표

계산 규칙이 어느 조문에 근거하는지, 언제 원문과 대조했는지, 아직 확인하지 못한 것이 무엇인지를 기록한다.
개정이 있으면 이 표에서 해당 규칙을 찾아 `index.html`의 함수와 `tests/`의 회귀 테스트를 함께 고친다.

- 기준일: 2026-11-06 (조문은 법제처·세법 DB 현행 원문과 연혁으로 대조)
- 법령 근거는 도리택스(taxdb)로 `get_article`·`get_article_history`·`get_amendments`를 열어 확인했다. 키워드 검색 결과만으로는 확정하지 않았다.
- 계산 코드는 `index.html` 한 파일 안에 있다. 회귀 테스트는 `tests/`에서 함수를 뽑아 실행한다 (`node tests/inheritance.test.mjs`, `node tests/gift.test.mjs`, `node tests/rollingwindow.test.mjs`).
- 상태: **확인** = 원문과 코드가 일치 / **근사** = 일부만 일치하거나 입력에 의존 / **미확인** = 대조하지 않음 / **수정** = 대조 중 오류를 찾아 고침

- `index.html`은 git에 LF(줄바꿈 `\n`)로 커밋돼 있다. 편집은 `git show HEAD:index.html` 내용을 기준으로 하고(작업트리 파일이 Windows에서 CRLF로 받아져 있을 수 있음), 푸시 전 `git diff --stat index.html`로 변경 줄 수가 실제 수정 범위만큼인지 확인한다(CRLF로 저장해 편집하면 파일 전체가 바뀐 것처럼 보일 수 있음).
